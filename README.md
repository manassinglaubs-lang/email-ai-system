# GenAI-Powered Email Classification and Automated Response System

Analyzes customer emails with a Groq-hosted LLM: category, priority, sentiment,
key information, recommended action and a drafted reply.

Tech: Python, Groq API, Streamlit

## Run locally
1. pip install -r requirements.txt
2. Create a .env file with GROQ_API_KEY=your_key
3. streamlit run app.py
